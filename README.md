# CODECRAFT_DS_03

## Task 03 - Decision Tree Classifier

### Objective
Build a Decision Tree Classifier to predict whether a customer will subscribe to a product or service based on demographic and behavioral data.

### Dataset
Bank Marketing Dataset

### Work Performed
- Loaded the Bank Marketing dataset.
- Checked the dataset structure and data types.
- Checked missing and unknown values.
- Checked the target variable distribution.
- Converted categorical variables using one-hot encoding.
- Converted the target variable into numerical values.
- Split the dataset into training and testing sets.
- Built a Decision Tree Classifier.
- Generated predictions on the test dataset.
- Evaluated the model using accuracy and classification report.
- Created a confusion matrix.
- Visualized the decision tree.
- Analyzed feature importance.

### Machine Learning Model
Decision Tree Classifier

### Model Configuration
- Test size: 20%
- Random state: 42
- Maximum tree depth: 5
- Stratified train-test split

### Evaluation
The model achieved approximately 89.84% accuracy on the test dataset.
